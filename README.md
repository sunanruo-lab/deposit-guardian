# 押金保卫局

年轻人的租房入住与退租交接助手。原生微信小程序，使用 TypeScript、WXML、WXSS 和 JSON 开发；不使用网页套壳、服务器、云开发、登录、AI 接口或第三方付费服务。

## 直接运行

1. 解压项目 ZIP。
2. 打开微信开发者工具，选择「导入项目」。
3. 目录选择解压后的 `deposit-guardian`（能直接看到 `project.config.json` 的目录）。
4. AppID 可先使用测试号；项目已配置 `touristappid` 供本地预览。
5. 点击「编译」。建议将基础库设为 3.7.10 或更新版本。
6. 拍照、相册保存、文件分享等能力请用真机预览最终验收；开发者工具模拟器对系统相册和文件分享的支持不完整。

项目不需要执行 `npm install`，也没有后端环境变量。

## 数据保存方式

- 档案结构保存在微信小程序本地缓存键 `dg_store_v1`，带 `version: 1` 格式版本。
- 用户选择的图片先经 `wx.compressImage` 压缩，再由小程序文件系统复制到 `wx.env.USER_DATA_PATH/dg_photos`；业务数据保存的是持久化路径，而不是临时路径。
- 签名 Canvas 导出后同样复制到持久化图片目录。
- 报告保存到 `wx.env.USER_DATA_PATH/dg_reports`，档案中保存报告路径和生成记录。
- 「我的 → 导出 JSON 备份」生成 JSON 并调用微信文件分享；导入时先完整解析和校验，校验失败不会改动现有数据，同 ID 项目采用新增副本方式合并，禁止静默覆盖。
- 删除小程序或清理微信数据可能导致记录丢失，请定期导出备份，并把重要报告保存到系统相册。

## 功能说明

- 房屋档案：新建、编辑、二次确认删除、复制、搜索、阶段筛选和创建时间排序。
- 入住检查：7 类默认房间和完整默认检查项；支持自定义房间、检查项、状态、严重程度、说明和多图。
- 退租检查：沿用入住清单，显示入住原始状态与照片，记录退租状态和四类变化结论，汇总变化项。
- 表计：入住/退租读数、单位、照片、时间与差值；差值不用于计算账单。
- 钥匙门禁、家具家电、问题档案：完整增删改、图片、筛选和解决状态。
- 交接确认：双方信息、补充说明、Canvas 手写签名、清除和重新签署。
- 报告：五类报告、生成进度、中文换行、内容分块分页、照片、签名、页眉页脚、预览、重试、删除和相册权限引导。
- 本地数据：统计、JSON 导出/导入、未引用照片清理、双重确认清空。
- 首次隐私说明：只在用户主动选择照片或保存报告时调用相关系统能力。

## 演示数据

正式首页不显示假数据。在「我的」页面连续点击「关于押金保卫局」5 次会开启开发测试入口；可载入覆盖三个房间、正常项、轻微损坏、三类表计、钥匙、家具家电和双方签名的演示项目。演示项目可以正常生成完整报告，也可从档案页删除。

## 本地检查

项目附带无第三方依赖的结构检查：

```bash
node tools/validate.mjs
```

它会检查 JSON 可解析、`app.json` 中每个页面的四件套文件、WXML 事件是否有同页处理函数、核心文件是否齐全，以及是否出现云开发、网络请求、上传、TODO 或「功能开发中」占位。

TypeScript 的最终编译由微信开发者工具内置 TypeScript 编译插件执行；`types/wx.d.ts` 为离线检查提供最小微信全局声明。

## 真机验收建议

依次测试：创建档案 → 入住检查拍照 → 杀掉并重开小程序确认照片仍在 → 录入入住/退租表计核对差值 → 退租对照 → 双方签名 → 生成多页报告 → 预览并保存相册 → 导出 JSON → 新建空环境后导入。首次拒绝相册权限后再次保存，应出现前往设置的引导。

> 本工具仅用于整理和保存交接记录，不构成法律意见或证据效力承诺。
